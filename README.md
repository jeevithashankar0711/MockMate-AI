\# MockMate AI – AI-Powered Mock Interview Platform



\## About the Project

MockMate AI is an AI-powered interview preparation platform designed to help students and job seekers improve their interview skills through mock interviews, automated answer evaluation, and resume analysis.



\## Features

\- \*\*AI Mock Interviews:\*\* Practice interviews for different technical roles and difficulty levels.

\- \*\*AI Answer Evaluation:\*\* Get scores, feedback, and AI-generated suggested answers.

\- \*\*ATS Resume Checker:\*\* Analyze resumes based on job requirements.

\- \*\*Dashboard:\*\* Track interview performance and results.

\- \*\*User Authentication:\*\* Login and registration functionality.

\- \*\*Profile Management:\*\* Manage user profile information.



\## Technologies Used



\*\*Frontend:\*\*

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



\*\*Backend:\*\*

\- Go (Golang)

\- REST API



\*\*AI Integration:\*\*

\- Google Gemini API



\## Project Structure



\- `frontend/` – User interface and frontend application.

\- `backend/` – Backend APIs and AI evaluation logic.



\## Project Objective



The main objective of MockMate AI is to make interview preparation easier and more effective by providing AI-powered interview practice, personalized feedback, and resume analysis.
